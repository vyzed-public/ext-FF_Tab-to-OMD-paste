# ext-FF_Tab-to-OMD-paste
Browser extension (for Firefox) to edit &amp; bookmark Tabs into pasteable (Obsidian-style) Markdown

We use AI (Claude Opus 4.6) to "vibe-code" a custom personal browser extension (for Firefox) to select (& edit) tab titles and generate bookmarks in Obsidian-style markdown (OMD), storing the OMD content in the system clipboard buffer, ready for pasting into an OMD (or any markdown) document.

## Installation:

### Development/Debugging:

Use Firefox Internal URI:  `about:debugging#/runtime/this-firefox` to `[Load Temporary Add-On...]`
